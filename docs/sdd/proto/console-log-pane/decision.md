# console-log-pane — prototype decision

**Chosen:** варіант A. Зверху рамка `BACKGROUND` з вкладками задач, під нею рамка `OUTPUT` з логом вибраної задачі на всю висоту панелі (`v2-final/`).

**Why:** вкладки займають один рядок, тож майже вся висота лишається логу. Заголовок у рамці продовжує стиль нижньої HUD-панелі. Варіант B забирав близько 30% ширини під список, а варіант C зовсім не схожий на решту інтерфейсу.

**Changed while debugging:**
- Розмір брати з `e.props.bodyColumns` і `e.props.scroll.bodyRows`. `e.viewport` описує весь термінал, і через нього рамки переносились, а наприкінці кожного рядка стояв `…`.
- Рамки малюються вручну одним `Text` на рядок, із точною шириною. `Box` не вміє ставити заголовок у рамку.
- Палітра як у HUD: рамки `gray`, заголовки `cyan` жирним, підписи dim. Статуси: `◐` yellow (running), `✓` green, `✗` red, `■` gray. Тло вмісту `black`.
- Вкладки зроблено через `Button plain`, бо звичайна кнопка в терміналі малює `[ … ]`. Підпис вкладки — це `description` Bash-виклику, а не сирий shell.
- `OUTPUT` доповнюється порожніми рядками до висоти панелі, щоб нижня рамка стояла над полем вводу.
- Керування моду — лише `ctrl+→` / `ctrl+←`:
  - з промпту `ctrl+→` дає фокус панелі на першій задачі;
  - у панелі `ctrl+→` веде до наступної задачі й на останній зупиняється;
  - `ctrl+←` веде до попередньої, а на першій задачі повертає фокус у промпт.
- Прибрано hotkeys `1`–`9`, дії на клік, прокрутку й підкоманди. Лишилась одна команда `/console-log` без аргументів, вона відкриває панель.
- Engine замикає фокус у кільце, тому `previous` з першої вкладки переходить на останню. Повернення в промпт зроблено через невидиму кнопку `key="exit"` перед вкладками: `ui.focus` на ній закриває панель і відкриває її знову без фокусу. API, яке віддає фокус промпту напряму, відсутнє.
- Перехід по колу з останньої вкладки вперед на `exit` відхиляється.
- Життєвий цикл задачі:
  - ✓ зникає через 10 с;
  - ✗ і ■ лишаються, поки користувач не відкриє вкладку й не піде з неї;
  - без задач панель закривається.
- Код виходу буває від'ємним (`exit code -1` при обриві сесії), тому регулярний вираз — `-?\d+`.
- Після reload мода таймер опитування втрачається. `session.start` перезапускає його, якщо є задачі зі статусом running.

**Ruled out:**
- Варіант B (бічний список): забирає ширину в лога.
- Варіант C (компактні вкладки без рамок): не схожий на HUD.
- Вимикати стандартні `←`/`→`/Tab у `keybindings.json`: це зачепить панелі всіх плагінів. До того ж це шлях, який працює без налаштувань.

**Open:**
- `ctrl+→` / `ctrl+←` працюють лише з рядками в `~/.claude/keybindings.json` користувача (`v2-final/keybindings.json`), бо плагін не може постачати власні клавіші. Без них працюють стандартні `ctrl+x tab`, `←`/`→` і `esc`.
- Сірий рядок над панеллю й під нею — це рамка пристикованої панелі, яку малює engine. Мод її не контролює.
- Звичайні `←`/`→`, Tab і клік мишею теж рухають фокус по вкладках. Це стандарт engine, його залишено свідомо.
